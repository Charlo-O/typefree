## Architecture Map

- Runtime boundary: default desktop runtime is Tauri v2 under `src-tauri/`; Electron-era files are removed from the root and preserved under `legacy-electron/`.
- UI platform boundary: UI-facing desktop access goes through `src/shared/platform`, with legacy compatibility kept behind the bridge.
- Dictation flow: `src/features/dictation` owns recording orchestration, the explicit session state machine, frontend pipeline stages, and timeline capture.
- Backend transcription flow: Rust command facades live in `src-tauri/src/commands/`; provider dispatch and event contracts live in `src-tauri/src/transcription/`.
- Persistence boundary: settings live in schema-driven frontend state plus backend app-data settings; secrets go through `src-tauri/src/commands/credentials.rs`; history/timeline live in SQLite via `src-tauri/src/commands/database.rs`.
- Diagnostics boundary: developer smoke probes are exposed from the control panel and executable through `scripts/run-tauri-dev-smoke.js`.

- `npm run import:runtime-smoke-evidence -- --source <runtime-smoke-evidence-platform-dir-or-manifest> --manifest-dir <dir>` validates a returned platform bundle with `--require-cloud-microphone`, requires a parseable manifest `collectedAt`, rejects path escapes and secret/transcript payload keys, copies only the manifest plus five summaries into the integration manifest directory, and validates the imported copy. If `--source` is a directory containing one-level `runtime-smoke-evidence-*` child bundles, it can import the returned macOS/Linux evidence bundles in one pass; child directory platform, manifest filename platform, and manifest `platform` must match, duplicate platforms fail closed, and `--replace` verifies a temporary copy before swapping.
- `npm run handoff:runtime-smoke-evidence -- --cloud-provider <provider> --cloud-model <model> --cloud-language <lang> --cloud-smoke-ms <ms> --bundle-dir <dir>` writes a transferable command bundle with per-platform collector scripts, import-returned-evidence helper scripts, and final readiness scripts without running Tauri, reading credentials, recording audio, calling providers, or writing runtime evidence. The generated scripts locate the TypeFree repo root from the current directory or the handoff script path before invoking `npm`/`node`, so they can be launched from the repo root or the handoff bundle directory and fail closed when the repo root cannot be found.
- `npm run verify:runtime-smoke-handoff-bundle -- --bundle-dir <dir>` validates a generated handoff command bundle before transfer. It reads only the bundle files and rejects path escapes, unknown executable scripts, fixture/allow-missing cloud shortcuts, secret/transcript payload keys, import helpers that bypass `scripts/import-runtime-smoke-evidence.js`, and final readiness commands that bypass `verify:goal-readiness -- --manifest-dir`.
- `npm run verify:runtime-smoke-summaries -- --platform <platform> ...` validates collected `.codex-run-logs/*.summary.json` artifacts for runtime readiness, native capture, dictation pipeline persistence, credential preflight, and cloud transcription summary hygiene. Add `--require-cloud-microphone` when the cloud transcript evidence is meant to prove the native microphone recording -> provider transcription path; that stricter mode rejects speech-fixture-only summaries. The verifier is intentionally outside default verify gates because it consumes external smoke artifacts.
- `npm run verify:goal-readiness -- --manifest-dir <dir>` is the shortest preferred final machine gate when the required Windows platform bundle is present; explicit `--windows-manifest <manifest>` and `--windows-runtime-probe <summary> ...` style paths remain supported. Optional `--macos-manifest <manifest>` and `--linux-manifest <manifest>` are still accepted and strictly validated when provided. It requires the local implementation evidence, the default local verification wiring, portable manifest path safety, and strict `--require-cloud-microphone` runtime summary validation for the required Windows live evidence. When required evidence is missing, the failure output scopes `handoff:runtime-smoke-evidence -- --platform <missing-platforms> --bundle-dir <dir>` plus `verify:runtime-smoke-handoff-bundle` to the missing platform set.
